# NORTHSTAR Foundation

Long-term, slow-changing context for NORTHSTAR. Company, product, KPI definitions, and the record of decisions that are expensive to reverse.

If it changes weekly, it does not belong here.

## What's in here

| File | What it holds |
|---|---|
| [Context](context.md) | Company, product, users, moat. What NORTHSTAR is and who it's for. |
| [Apps](apps.md) | One paragraph per repo: what it is and where it's going. |
| [Working Agreement](working-agreement.md) | How I work. The rules I check myself against. |
| [Decisions](decisions) | Cross-cutting ADRs. Dated, numbered, never edited after the fact. |

## Where everything else lives

**Google Drive** — anything we revise together or that changes often.
- Strategy: Now / Next / Not now
- Research and open exploration
- Customer notes

**GitHub Issues** — the engineering queue, filed in the repo where the code changes. One org-level Project spans all repos.
